Open MCP CAD

The first public MCP server for Cadwork.

Open MCP CAD connects your AI assistant to Cadwork while it is running. An MCP server and a Cadwork plugin allow a language model to read and create geometry directly in your open 3D document. You describe what you need instead of clicking through menus. It was developed over several months in real, everyday timber construction work.

  • Every write access needs your approval and can be undone
  • For MCP-capable assistants such as Claude Desktop, Claude Code or Codex
  • Several Cadwork windows in parallel, cleanly separated
  • Runs locally, with no account and no cloud in between
Download (.zip) View on GitHub
WhatsApp LinkedIn Email

Installation: unzip the ZIP file and double-click install.cmd. Do not copy the source code from GitHub into Cadwork yourself. Requirements: Windows, Cadwork 3D 2026, Python 3.10 to 3.13. If Python is missing, the installer offers to install it. The installation guide is available in German, English, French and Italian.

LignoCAD Tragwerk

Position plans and load transfer plans, created quickly and cleanly.

Import a base plan as PDF, DWG or DXF, calibrate it, position the structural members and transfer loads storey by storey. The result is a scaled drawing sheet, just as Swiss timber engineers are used to.

  • PDF, DWG and DXF import with snapping to plan points
  • Position plan and load transfer in one file
  • Scaled PDF output without a print dialog
  • Works locally, your projects stay on your computer
